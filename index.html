자동 배정 규칙(FIFO)
입금이 들어오면 가장 오래된 미납/부분납 월부터 순서대로 채웁니다.
남는 금액은 선수금(크레딧)으로 저장되며, 다음 달 생성/재계산 시 자동으로 당겨 쓸 수 있게 확장할 수 있습니다.

입금 등록 (자동 배정) 총무 전용

큰 금액을 한 번에 넣어도 미납월부터 자동으로 채우고, 남으면 선수금으로 잡힙니다.
선택 이벤트 미납분부터 차감, 남으면 선수금 -
팁: 회원이 “작년 미납 + 올해 몇 달치”를 한 번에 내도 월회비 자동배정으로 넣으면 알아서 정리됩니다.

기타 수입 등록 (이자/찬조금 등) 총무 전용

회원의 월회비나 경조사 갹출이 아닌 모임 통장 자체의 기타 수입(예금 이자, 외부 찬조금 등)을 기록합니다.

지출 등록 총무 전용

식비/경조사/기타 지출을 간단히 기록합니다.
단순 경조사 지출 기록용 본인 표시

경조사 이벤트 생성 (선지출 + 1인당 갹출) 총무 전용

모임통장에서 먼저 지급(선지출)하고, 당사자(본인)를 제외한 회원들에게 1인당 금액으로 갹출 미납을 자동 생성합니다.
대상 인원 계산중... -
생성 시 자동으로 ① 지출(경조사 선지출) 거래가 기록되고(실제 통장 선지출액을 따로 적으면 그 금액만큼만 지출 기록), ② 대상 회원 전원에게 미납(1인당 갹출금)이 생성됩니다.
실수로 잘못 만든 경우 아직 입금자가 0명이면 대시보드 상세 보기에서 이벤트 취소(삭제)로 선지출 내역까지 한 번에 되돌릴 수 있습니다.

입력 실수 정정(거래 삭제) 주의

잘못 입력한 입금/지출을 삭제하면 배정된 월회비/선수금도 함께 되돌립니다.

월 데이터(청구서) 생성 / 일괄 재계산 자동화됨

올해 12월까지의 월별 청구서는 총무 로그인 시 자동 생성됩니다. 과거 연도나 미래 연도를 수동으로 만들거나 전체 회원을 일괄 재계산할 때만 사용하세요.
자동 처리 안내
• 신규 회원 추가 / 총무 로그인 시: 올해 말(12월)까지의 월 청구서가 비어 있으면 백그라운드에서 자동으로 생성됩니다.
• 전체 회원 범위 재계산: 회비 변경이나 면제 수정 후 이미 납부된 금액(paid)은 그대로 보존하면서 청구 금액(due)과 완납/미납 상태만 전체 회원에게 일괄 재적용합니다.

회원 제명(활동종료) 처리

과거 입출금 거래 내역과 현재 통장 누적 잔고에는 단 1원의 영향도 주지 않고 향후 회비 및 경조사 대상에서 제외합니다.

※ 이미 납부(부분납 포함)한 달이나 납부한 경조사 내역은 절대 건드리지 않고 그대로 보존됩니다.

📘 총무 사용 안내서 (인수인계 매뉴얼)

총무님이 바뀌더라도 별도의 설명서 없이 바로 업무를 파악하실 수 있도록 핵심 운영 요령을 정리했습니다.

1. 화면 새로고침 요령 (키보드 F5 대신 앱 내부 버튼 사용!)

  • 입금·지출·경조사·제명 등 모든 작업은 저장 즉시 화면에 자동 반영되므로 F5 키를 누르실 필요가 없습니다.
  • 브라우저에서 F5(새로고침)를 누르면 보안상 로그인이 풀려 암호를 다시 입력해야 하고, 파이어베이스 무료 데이터베이스 읽기 한도를 불필요하게 소모합니다.
  • 다른 기기에서 입력한 최신 내역을 확인하고 싶을 때는 각 항목 우측의 [새로고침] 또는 [조회] 버튼을 눌러주세요.

2. 월회비 입금 & 회비 금액 변경

  • 월별 청구서 자동 생성: 총무 암호로 로그인하면 올해 12월까지의 월별 청구서가 자동으로 생성됩니다.
  • 목돈 입금 자동배정(FIFO): 회원이 여러 달치 회비를 한 번에 입금해도 [월회비 자동배정]으로 등록하면 가장 오래된 미납월부터 순서대로 채워지고, 남은 돈은 선수금(크레딧)으로 자동 적립됩니다.
  • 회비 인상/변경: [설정] 탭에서 적용 시작월과 금액을 입력한 뒤 [저장(전체 회원 자동 반영)] 버튼 하나만 누르면 전체 회원에게 일괄 반영됩니다.

3. 경조사 이벤트 생성 · 취소 · 장기미납 제외

  • 선지출 금액 분리 입력: 모임통장에서 나간 실제 금액과 1인당 갹출 총액이 다를 경우, [실제 통장 선지출액] 칸에 실제 통장에서 지출한 금액을 적어주세요.
  • 잘못 만든 이벤트 취소: 아직 입금자가 0명일 때는 대시보드 경조사 [자세히 보기] → [이벤트 취소(삭제)]를 누르면 자동으로 기록된 선지출 내역까지 한 번에 깔끔하게 취소됩니다.
  • 장기미납자 징수포기(완료 처리): 끝까지 갹출금을 내지 않는 회원은 경조사 [자세히 보기]에서 우측 [징수포기(제외)]를 누르면 기존 통장 잔고 훼손 없이 해당 회원을 제외하고 이벤트를 완료(숨김) 처리할 수 있습니다.

4. 탈퇴 회원 제명(활동종료) 및 연습모드 활용

  • 회원 제명: [회원] 탭 우측 목록에서 [제명(활동종료)]를 누르면 과거 입출금이나 누적 잔고에는 단 1원의 영향도 주지 않고, 향후 회비 청구 및 진행 중인 경조사 미납을 일괄 정리할 수 있습니다.
  • 연습모드 활용: 기능이 헷갈릴 때는 상단의 [모드 전환(실전/연습)]을 눌러 연습모드에서 마음껏 테스트해 보세요. 실전 장부 데이터에는 아무런 영향을 주지 않습니다.
